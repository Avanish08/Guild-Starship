# Unity Runner Game

This is a simple 2D endless runner game made in Unity.  
The player can move vertically, collect coins, use fire bullets, and activate shields.

---

## 🎮 Controls

### **Mouse / Touch (Mobile & Editor):**
- **Tap / Click on left side of the screen**  
  Move player **up** if tapped above player, **down** if tapped below player.

### **Shooting Fire Bullets:**
- **Press Fire Button** (UI button)  
  Shoots a fire bullet if player has fire ammo collected.

### **Collect Power-ups:**
- **Fire Bullet Power-up:** Increases ammo count.
- **Shield Power-up:** Activates shield for 10 seconds, protecting the player from obstacles.

### **Pause Menu:**
- **Pause Button:** Pauses the game.  
- **Resume Button:** Resumes gameplay.  
- **Quit Button:** Returns to main menu.

## ⚡ Gameplay Mechanics
- Player moves forward automatically.  
- Obstacles spawn randomly; avoid them or use shield.  
- Game over triggers the death panel with options to **Retry** or **Return to Main Menu**.
